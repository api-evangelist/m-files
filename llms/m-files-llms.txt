# M-Files

> M-Files is a metadata-driven document and information management platform that connects
> documents to business context. It provides AI-powered document management with built-in
> governance, automation, and compliance, integrates deeply with Microsoft 365, and is used
> by 6,000+ organizations. Developers integrate via the M-Files Web Service (MFWS) REST API,
> the COM/.NET API, and the UIX and Vault Application Framework (VAF) extensibility frameworks.

## APIs

- [M-Files Web Service (MFWS) REST API](https://developer.m-files.com/APIs/REST-API/): JSON/HTTPS REST API served per M-Files Server / Cloud vault under /REST/.
- [REST API Reference](https://developer.m-files.com/APIs/REST-API/Reference/): Endpoint reference.
- [COM/.NET API](https://developer.m-files.com/APIs/COM-API/): Comprehensive user + administrative API for Windows.
